# TerraBrief

TerraBrief is a personal AI morning briefing system.

It collects news from RSS feeds, filters stories according to configured
interests, sends them to an AI model for analysis, and generates a daily
briefing.

## Topics

- UK
- World
- Technology
- Aviation
- Formula 1
- Gaming

## Requirements

- Python 3.12+
- Ollama
- An Ollama-compatible AI model
